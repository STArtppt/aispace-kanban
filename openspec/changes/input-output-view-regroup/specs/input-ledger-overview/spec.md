## ADDED Requirements

### Requirement: 去掉概览视图

导航 SHALL NOT 再有「概览」。视图只剩「输入资料」「产出文档」及原有其他视图，进入看板默认停在「输入资料」。
会话里记住的视图是 `overview`（旧版本留下的）或不认识的值时，SHALL 退回「输入资料」，不白屏。

#### Scenario: 旧会话值

- **WHEN** 本地存储里记着上次停在 `overview`，用户刷新看板
- **THEN** 打开的是「输入资料」，导航里没有「概览」

### Requirement: 资料台账行

「输入资料 → 原始资料」列表顶部 SHALL 固定一行「资料台账」，不参与搜索过滤与状态筛选、不随分页移动。
行内显示副标题：有 `input/INDEX.md` 时写「INDEX.md · 资料最后入库 <相对时间>」，没有时写「项目概览」。
点击后在预览窗口打开台账预览。工作空间目录丢失时这一行不出现。

#### Scenario: 打开台账

- **WHEN** 用户点「原始资料」里的「资料台账」
- **THEN** 右侧预览窗口显示台账预览，列表保持原位

#### Scenario: 搜索时仍在

- **WHEN** 用户在原始资料里搜索一个不存在的关键词
- **THEN** 列表空态提示「没有匹配的原始资料」，「资料台账」行仍在顶部

### Requirement: 台账预览里的概览

台账预览 SHALL 由上下两部分组成：上部是精简概览，下部是 `input/INDEX.md` 的 markdown 正文（没有就省略，不显示空态）。
精简概览包含且只包含：
- 抬头：项目名（`project.yaml` 有则取，否则工作空间名）与阶段（有则显示）；
- 三格统计：资料（转换产物数，提示原始文件与忽略数）/ 产出（三组总数与字数）/ 待办信号（待转 + 存疑 + 原件已改，非零时 orange）；
  有 `project.yaml` 统计时第一格换成完整度；
- 四步进度（资料入库 / 需求分析 / 文档交付 / 视觉呈现），带「推断」标记，单行紧凑排列；
- 项目元信息摘要（沿用元信息视图），带「看原文」；没有 `project.yaml` 时给一段说明如何生成。
视觉 SHALL 只用 `globals.css` 令牌，黑白灰为主，orange 只给待办信号与需要注意的项；窄预览宽度下统计格可换行，不出现横向滚动。

#### Scenario: 没有 project.yaml 的工作空间

- **WHEN** 工作空间没有 `project.yaml`，用户打开台账
- **THEN** 抬头显示工作空间名，四步进度带「推断」，元信息区是生成说明，页面不报错

#### Scenario: 深色模式

- **WHEN** 用户切到深色模式打开台账
- **THEN** 概览与正文颜色都跟随令牌，无硬编码色值

#### Scenario: 旧服务进程

- **WHEN** 前端已更新、服务进程还是旧的（缺新字段）
- **THEN** 台账照常打开，缺的统计按 0 或省略显示
