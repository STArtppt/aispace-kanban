## **基础地理模型**

地理基础模型是构建基础地理场景的主要要素，主要通过遥感卫星、无人机航拍等方式采集数据，数据包括数字高程模型（DEM）、数字正摄影影像图（DOM）、倾斜摄影模型、矢量地理数据集。这些数据的存储采用空间数据库的存储方式实现，不需要再建设各个基础地理数据的属性表和索引表，统一使用基于关系数据库系统的空间数据引擎进行存储与管理。

1.  **数字高程模型（DEM）**

数字高程模型的英文全称Digital Elevation Model，是研究分析地形、流域、地物识别的重要原始资料。由于DEM 数据能够反映一定分辨率的局部地形特征，因此通过DEM 可提取大量的地表形态信息，可用于绘制等高线、坡度图、坡向图、立体透视图、立体景观图，并应用于制作正射影像、立体地形模型与地图修测。

2.  **数字正摄影像图（DOM）**

数字正射影像图（Digital Orthophoto Map，缩写DOM）是利用数字高程模型（DEM）对经扫描处理的数字化航空像片，经逐像元进行投影差改正、镶嵌，按国家基本比例尺地形图图幅范围剪裁生成的数字正射影像数据集。它是同时具有地图几何精度和影像特征的图像，具有精度高、信息丰富、直观真实等优点。数据格式采用Geotiff（带坐标的tif格式）。

> 〔配图已移除〕数字正射影像图（DOM）成果示例——带地理坐标的正射影像底图

3.  **倾斜摄影模型**

倾斜摄影是通过在同一飞行平台上搭载多台传感器，同时从一个垂直、四个倾斜等五个不同的角度采集影像。无人机航拍的影像经过建模软件处理产出OSGB，OBJ，FBX，STL等格式模型数据。

航空倾斜影像不仅能够真实地反应地物情况，而且还通过采用先进的定位技术，嵌入精确的地理信息、更丰富的影像信息、更高级的用户体验，极大地扩展了遥感影像的应用领域，并使遥感影像的行业应用更加深入。

4.  **矢量地理数据集**

矢量数据（Vector Data）是用X、Y、Z坐标表示地图图形或地理实体位置的数据。矢量数据一般通过记录坐标的方式来尽可能将地理实体的空间位置表现的准确无误。常见的矢量数据有：点、线、面等格式。

SHP (Shapefile)是目前最常见的一种矢量数据格式。作为行业标准，几乎所有的商业和开源GIS软件都支持Shapefile。一个Shapefile数据最少包括三个文件：

主文件（\*.shp）——存储地理要素的几何图形的文件。

索引文件（\*.shx）——存储图形要素与属性信息索引的文件。

dBASE表文件（\*.dbf）——存储要素信息属性的dBase表文件。

除此之外还有可选的文件，包括：空间参考文件（\*.prj）、几何体的空间索引文件（\*.sbn 和 \*.sbx）、只读的Shapefiles的几何体的空间索引文件（\*.fbn 和\*.fbx）等等。

## **三维实体模型**

三维实体模型包括建筑模型、发电设施模型、绿化模型以及其他模型等，各类模型按照表现细节的不同可分为LOD1、LOD2、LOD3三个细节层次，详见下表：

三维实体模型精度分类表

|              |          |          |          |
|--------------|----------|----------|----------|
| 模型类型     | LOD1     | LOD2     | LOD3     |
| 建筑模型     | 体块模型 | 基础模型 | 标准模型 |
| 发电设施模型 | 体块模型 | 基础模型 | 体模型   |
| 绿化模型     | 通用符号 | 基础模型 | 标准模型 |
| 其他模型     | 通用符号 | 基础模型 | 体模型   |

1.  **建筑模型**

（1）体块模型是根据建筑基底考虑建筑高度生成的平顶柱状模型，建筑物基底宜以1:500、1:1000、1:2000等比例尺地形图建筑轮廓线为依据，建筑高度可根据建筑性质采用对应的平均层高间接获得，也可通过航空摄影测量、机载激光扫描或野外实地测量等方式直接获得，平面尺寸精度约2m，高度精度约3m，对于高层建筑可放宽至5m。

（2）标准模型应精确反映房屋屋顶及外轮廓的基本特征，平面尺寸和高度精度约1.5m。

（3）精细模型应精确反映房屋屋顶及外轮廓的详细特征，平面尺寸和高度精度约1m。

> 〔配图已移除〕建筑三维模型示例——升压站建筑外轮廓与屋顶细节

2.  **电力设施相关模型**

电力设施模型指真实用于发电和参与发电的设施，如光伏发电板、逆变器(集中式)、逆变器(组串式)、电表、环境监测仪、交流汇流箱、直流汇流箱、箱变、组件、支架、升压站、断路器、主变和中控室这些设备的虚拟现实模型。

发电设施主要以体模型为主，应根据实际测量的物体尺寸和外业采集的纹理信息精细建模，应真实、准确的反映物体的各部位几何特征、样式、高度、分布、位置、质地、色彩及纹理等，模型细部可根据实际情况进行取舍，取舍掉的细部结构可采用纹理进行辅助表现，纹理贴图要求细节清晰，高度精度小于模型自身高度的10%。

基于工程信息、地理信息数据，通过三维建模技术、数字化协同设计技术的集成应用，完成输变电工程的三维可视化设计和信息一体化。

几何模型 geometric model 描述物理对象的外形、尺寸、位置、结构等几何信息的三维模型。

物理模型 physical model 描述工程建（构）筑物、设备、材料及其他设施等物理对象的三维模型，由几何模型及其属性构成。

3.  **绿化模型**

（1）基础模型宜采用单面片、十字面片或多片面的形式表现，位置及几何尺寸宜与现状吻合。纹理宜采用简单贴图，基本反映树木的形态、高度、分布等主要特征，树木高度与实际误差在5m以内。

（2）标准模型采用十字面片或多片面的形式表现，参考现场照片真实反映树木的形态、高度、分布、位置、种类及色彩等特征。

（3）精细模型采用简单几何树干模型和多面片树冠形式进行建模，参考现场照片真实反映树木的形态、高度、分布、位置、种类及色彩等特征。

（4）绿化模型主要为行道树和景观树，在场景表现时宜按照上述不同细节层次建立。

> 〔配图已移除〕绿化模型示例——面片树在场景中的表现效果

4.  **其他模型**

（1）基础模型应以实际测量数据为依据，结合真实的纹理图片，宜采用单面片、十字交叉面片、多面片或简单的方式，采用透明通道的方式简单表现建模物体的基本形态、样式、高度、分布、位置及纹理特征，纹理宜采用简单贴图，高度精度小于模型自身高度的20%。

（2）体模型应根据实际测量的物体尺寸和外业采集的纹理信息精细建模，应真实、准确的反映物体的各部位几何特征、样式、高度、分布、位置、质地、色彩及纹理等，模型细部可根据实际情况进行取舍，取舍掉的细部结构可采用纹理进行辅助表现，纹理贴图要求细节清晰，高度精度小于模型自身高度的10%。

5.  **设备与模型关联设计**

数字孪生三维虚拟场景中，数据访问都要通过点击三维模型来实现，如何将模型属性与设备数据关联，如何建立模型与设备间的唯一标识码，至关重要。现实中，常用的电厂标识系统即KKS，是一种根据功能、型号和安装位置来明确标识发电厂中的系统、设备、组件和建构筑物的编码体系。解决信息分类与编码是实现电厂数字化的基础。KKS编码是指电厂中各种对象按照其内在联系进行统一分类、统一编码、统一标识的过程和方法，使各种对象的相关信息在电厂的整个生命周期内都具有唯一的标识。

本系统的实体模型，通过利用KKS标识编码，建立了完整的数字孪生电站模型编码体系，实现了模型属性数据与设备业务数据的关联，确保方便灵活的信息查询得以实现。本系统中的模型编码规范(见附录D)，参考标准为《GB/T 50549-2010 电站标识系统编码标准》、《QSPI 9720-2016 光伏发电站标识系统（KKS）编码规范》两种。
