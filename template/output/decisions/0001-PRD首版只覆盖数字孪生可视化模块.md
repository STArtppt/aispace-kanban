# 0001-PRD 首版只覆盖数字孪生可视化模块

- 日期：2026-07-31
- 状态：已确认
- 决策：需求规格说明书 V1.0 只写「数字孪生可视化」一个模块
  （三维建模成果的消费侧 + 三维可视化 + 运行可视化 + 告警着色 + 视频联动），
  人员定位类功能、风电场部分、第 3 章特色功能均不成文。
- 背景：现有资料只有一份方案建议书
  （`input/converted/新能源场站数字孪生集成平台方案建议书.md`），
  其中只有「数字孪生业务功能设计」一章的描述达到可拆解粒度；
  人员定位类功能涉及员工位置轨迹，合规方案全空白（见决策 0002）；
  覆盖范围里的 4 座风电场在正文中零描述；
  第 3 章标题自标「(待完善)」，其中两项只有一张架构图或一个标题加省略号。
  强行凑齐全部内容，只能靠推断填充，违反工作空间「不用推断填平资料空白」的约定。
- 代价：交付物暂时不完整，无法用于整体报价或整体评审；
  尤其**风电场部分缺失意味着约 1/3 的覆盖资产没有需求文档**，
  若甲方要求一次性看到全场站方案，需先补齐资料再出 V2.0。
