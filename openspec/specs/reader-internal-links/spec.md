# reader-internal-links

## Purpose

约定预览区（`Reader`）里 markdown 正文的链接行为：站内链接在当前预览区就地切换、
页内锚点在当前文档内滚动、行内代码里的工作空间路径自动成链接，并给预览区一条内存里的后退链。
预览区之外的 markdown（帮助面板、工作台问题详情）行为不变。

## Requirements

### Requirement: 站内链接在当前预览区打开

预览区（`Reader`）渲染的 markdown 正文里，看板 MUST 把满足下列条件的链接视为**站内链接**：目标按「当前文档所在目录」解析后落在工作空间内（不以 `http:` / `https:` / `mailto:` / `data:` / `blob:` / `#` 开头，且解析结果不越出工作空间根）。

对站内链接的普通左键点击，看板 MUST 阻止浏览器默认跳转，MUST 在当前预览区切换到目标文件，
并按该文件在扫描结果中的阅读器类型渲染（markdown、表格、图片、代码、html、转换产物等）。
MUST NOT 新开浏览器窗口，MUST NOT 以源码形式展示 markdown 目标。

目标在扫描结果中的判定 MUST 覆盖 `input/raw`、`input/converted`（含多表产物的分表）、
`input/assets`（含图库）、`output/analysis`、`output/docs`、`output/decisions` 与 `project.yaml`，
与刷新后恢复预览时的查找口径一致。

这条要求 MUST 覆盖预览区里所有 markdown 正文：普通文档、转换产物的摘要（`_manifest`）
以及表格产物的台账摘要 —— 不能只有其中一处生效。

打开目标文件 MUST 走既有 `GET /api/projects/:id/file`，MUST NOT 新增接口，
MUST NOT 修改 `src/app/lib/api.ts` 的类型。

#### Scenario: 点台账链接就地打开
- **WHEN** 预览一份 `output/analysis/` 下的分析文档，其中有 `[台账](../../input/converted/<目录>/_manifest_<名>.md)`，用户左键点它
- **THEN** 预览区切换到该转换产物，按转换产物的样式渲染（溯源栏、摘要等）
- **AND** 没有新开浏览器窗口

#### Scenario: 点问题单之外的 markdown 链接
- **WHEN** 分析文档里有指向 `../decisions/<某决策>.md` 的链接，用户左键点它
- **THEN** 预览区切换到该决策文档并以 markdown 渲染，文档目录随之更新

#### Scenario: 台账摘要里的链接同样生效
- **WHEN** 预览一份表格产物的台账摘要，摘要里有相对路径链接，用户左键点它
- **THEN** 行为与普通文档里的站内链接一致

#### Scenario: 中文路径
- **WHEN** 链接目标含中文目录或文件名（markdown 里可能已被百分号编码）
- **THEN** 解析出的路径与扫描结果中的路径一致，能就地打开，不出现二次编码

### Requirement: 修饰键点击与外部链接保持浏览器默认行为

站内链接的 `href` MUST 仍指向该文件的原始文件地址（`api.fileUrl`）。
用户按住 ⌘ / Ctrl / Shift / Alt 点击，或用鼠标中键点击时，看板 MUST NOT 拦截，
由浏览器按默认行为处理（通常是新开窗口看原始文件）。

`http(s):` 与 `mailto:` 链接 MUST 保持改动前的行为：新开窗口、`rel="noreferrer"`。

#### Scenario: ⌘ 点击仍新开窗口
- **WHEN** 用户按住 ⌘（或 Ctrl）点击一个站内链接
- **THEN** 浏览器新开窗口打开该文件的原始地址，当前预览不变

#### Scenario: 外链照旧
- **WHEN** 用户左键点击 `https://` 开头的链接
- **THEN** 新开浏览器窗口打开该网址，当前预览不变

### Requirement: 页内锚点在当前文档内滚动

目标以 `#` 开头的链接，看板 MUST NOT 新开窗口。点击时 MUST 在当前文档中查找
标题文本与锚点匹配的标题（比较前对两边做同样的规整：去首尾空白、转小写、空白与连字符视为等价、
解开百分号编码），找到就滚动到该标题；找不到 MUST 什么都不做，MUST NOT 报错。

#### Scenario: 锚点命中
- **WHEN** 文档里有 `[见下文](#数据概况)`，且文档中存在标题「数据概况」，用户点击它
- **THEN** 正文滚动到该标题，没有新开窗口

#### Scenario: 锚点未命中
- **WHEN** 锚点在文档里找不到对应标题
- **THEN** 页面不跳转、不报错、不新开窗口

### Requirement: 扫描结果之外的目标有兜底

站内链接的目标不在扫描结果中时，看板 MUST 按下列顺序处理：

1. 目标路径等于问题清单中某条问题的 `path`：MUST 打开工作台的「未决问题」页并选中该条，
   当前预览保持不变。问题清单尚未加载或不含该条时，按第 2 条处理。
2. 目标扩展名为 `.md` / `.markdown`：MUST 在预览区以 markdown 阅读器打开。
3. 目标扩展名为 `.txt` 或落在 `src/shared/codeLang.mjs` 的代码扩展名映射中：
   MUST 在预览区以文本 / 代码阅读器打开。
4. 其余情况：MUST 退回改动前的行为 —— 新开窗口打开原始文件地址。

按第 2、3 条打开的文件若读取失败（文件不存在、越出工作空间），预览区 MUST 显示
该阅读器既有的错误态，MUST NOT 白屏。

#### Scenario: 点问题单链接
- **WHEN** 分析文档里有 `[Q0001](../questions/Q0001.md)`，问题清单里有这一条，用户左键点它
- **THEN** 工作台打开到「未决问题」页，选中 Q0001
- **AND** 预览区仍停在原分析文档

#### Scenario: 点工作空间根的 README
- **WHEN** 链接指向 `output/README.md`（不在扫描清单里），用户左键点它
- **THEN** 预览区以 markdown 渲染这份 README

#### Scenario: 点脚本文件
- **WHEN** 链接指向 `scripts/<某脚本>.py`，用户左键点它
- **THEN** 预览区以代码高亮打开该脚本

#### Scenario: 点不认识的二进制
- **WHEN** 链接指向一个 `.sqlite` 文件，用户左键点它
- **THEN** 与改动前一样新开窗口，当前预览不变

#### Scenario: 链接指向不存在的文件
- **WHEN** 链接指向一个已被删除的 `.md`，用户左键点它
- **THEN** 预览区显示读取失败的提示，界面其余部分正常

### Requirement: 预览区可后退到跳转前的文件

通过站内链接（含行内代码自动成的链接）切换预览时，看板 MUST 记下跳转前的文件。
后退链非空时，预览区头部 MUST 显示「后退」按钮；点击后 MUST 回到上一份文件，并从链上移除它。

用户从清单、概览、搜索、收藏等**链接以外**的入口打开文件，或关闭预览、切换工作空间时，
后退链 MUST 清空。后退链只存在内存中，MUST NOT 写进 `localStorage`；
刷新页面后后退链为空是预期行为。

后退回的文件若已不在最新扫描结果中（被删除或移走），看板 MUST 跳过它继续后退；
链上没有可回的文件时 MUST 隐藏「后退」按钮。

#### Scenario: 连续跳转后逐级后退
- **WHEN** 用户从分析文档 A 点链接到台账 B，再从 B 点链接到源文件 C，然后点两次「后退」
- **THEN** 依次回到 B、A，此时「后退」按钮消失

#### Scenario: 从清单打开清空后退链
- **WHEN** 用户经链接跳转过一次后，又从产出清单里直接点开另一份文件
- **THEN** 「后退」按钮消失

### Requirement: 行内代码中的工作空间路径自动成链接

预览区 markdown 正文里的**行内代码**（不含围栏代码块）若是工作空间路径，看板 MUST 把它渲染为站内链接。判定条件是其文本去掉首尾空白与开头的 `./` 后：

- 按工作空间根解析，恰好等于扫描结果中某个文件的路径；或
- 按当前文档所在目录解析，恰好等于扫描结果中某个文件的路径，

此时链接 MUST 保留行内代码的等宽样式，点击行为与站内链接完全一致
（含修饰键、后退链）。两种解析都命中时 MUST 以工作空间根解析的结果为准。

匹配 MUST 是完整路径的精确相等：MUST NOT 做前缀匹配、模糊匹配或只按文件名匹配；
含空白的整段文本、表名、字段名等不是路径的行内代码 MUST 保持原样。
这条规则 MUST 只用扫描结果判定，MUST NOT 为此请求服务端。

#### Scenario: 源文件路径变成链接
- **WHEN** 文档里有 `` `input/raw/<目录>/<某导出>.csv` ``，且扫描结果的 `input.raw` 里有这个路径
- **THEN** 这段行内代码可点击，左键点击后预览区以表格打开该 csv

#### Scenario: 表名保持原样
- **WHEN** 文档里有 `` `schema.table 预报流量` `` 这类不是路径的行内代码
- **THEN** 它照旧显示为普通行内代码，不可点击

#### Scenario: 只写了文件名
- **WHEN** 行内代码只写了 `x.csv`，而工作空间里的文件路径是 `input/raw/<目录>/x.csv`，当前文档目录下也没有 `x.csv`
- **THEN** 不成链接

#### Scenario: 围栏代码块不受影响
- **WHEN** 一段 ```` ```bash ```` 代码块里出现工作空间路径
- **THEN** 代码块照旧渲染，路径不可点击

### Requirement: 预览区之外的 markdown 行为不变

帮助面板与工作台问题详情里的 markdown 正文，本变更 MUST NOT 改变其链接行为；
`Markdown` 组件在未收到站内链接相关参数时，MUST 与改动前的渲染结果一致。

#### Scenario: 帮助面板链接不变
- **WHEN** 在帮助面板里点击一个链接
- **THEN** 行为与改动前一致
