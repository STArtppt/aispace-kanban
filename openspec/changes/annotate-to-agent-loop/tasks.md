- [x] 1.1 写 rehype 插件:给元素盖源码位置属性 —— 属性名与语义**按外部契约 A2**:
      `data-source-file`(相对工作空间根)+ `data-source-range`(字节区间,左闭右开,`起,止`),
      两个同时存在才算声明(见 design 决策 2,改完再改的代价是重跑整套锚点验收);给"能放行内内容"的容器里的非空白文本节点包一层 `span` 也盖上,**跳过表格与列表的结构性节点**,并防止自己生成的 `span` 被再包一次(不防会无限递归)
- [x] 1.2 实现锚点算法:文本节点定位 → 元素兜底 → 行内标记向外吸附;文本长度与区间长度不等时退到节点边界

- [x] 1.4 用一篇真实的长 markdown 跑一轮随机选区压测,确认没有真实锚点错误
- [x] 1.5 实测长文档下包 `span` 的渲染开销,超出可感范围就记进 design 的 Risks 并想办法
