# raw-move 合成语料

`workspace/` 是一个最小工作空间，全部内容合成，不含真实资料（原件只是几行文字，不是真的 Word / PDF）。
`pnpm test:raw-move`（`scripts/check-move-raw.mjs`）把它拷到临时目录，连同模板 `scripts/*.py` 一起，
用 `scripts/move_raw.py` 预览、执行，断言：

- 预览不改任何文件，排除范围（`.claude/`、`input/sources/`、`visualization/`）的命中不出现在预览里；
- 文件改名：原件留在原目录、字节不变；产物搬到 `layout.py` 算出的新落点，`source` 跟进；
  台账行、人工批注里的链接、原稿里的相对链接 / 根路径 / wikilink、docx 模板 JSON 的整值、`project.yaml` 都跟进；
  人工批注里的普通句子、代码块里的链接、记录状态流水、交付稿正文、Word 成品不动；交付稿 `source_sha` 换新；
- 文件名带 `[ ]` 的字面忽略规则跟着改，改完仍是「忽略」；
- 目录移动：镜像目录一起搬，换了深度的图片链接（Markdown 与 `<img>`）按新位置重算，图片本身不动；
  通配符忽略规则不改、单列进预览；未分类图片清单里的原件路径跟进；
- 点表文件单独改名、点表集移进子目录都被拒且磁盘不变；点表集原地改名时合并摘要改名、`source` 与台账行跟进；
  现场实测数据文件单独移动时摘要和正文目录一起搬；
- 落点冲突退出 2；同时改名又换目录、移出 `input/raw/`、移进自己、非法名字退出 4；
  预览后原件被改、目录里多了文件都退出 3 且不落盘；只改大小写放行；产物还在 `input/converted/` 时拒绝；
- 每次整理后用看板的 `scanWorkspace` 核对：整理前「已转」的仍是「已转」、不报原件已改，「忽略」的仍是「忽略」。

改整理规则或链接识别规则时同步改这里的断言；不要往这里放真实资料。
