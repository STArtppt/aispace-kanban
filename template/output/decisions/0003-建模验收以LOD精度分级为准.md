# 0003-建模验收以 LOD 精度分级为准，不采用「1:1 还原」表述

- 日期：2026-07-31
- 状态：待确认
- 决策：三维模型的验收口径**一律以逐类模型的 LOD 档位 + 精度数值为准**，
  合同与验收文件中不使用「1:1 镜像还原」「全息复制」这类表述；
  同时要求在需求确认阶段逐类锁定档位：建筑、发电设施、绿化、其他四类模型
  各自交付到 LOD1 / LOD2 / LOD3 中的哪一档。
- 背景：资料 §1 开篇称「以 1:1 镜像还原物理电站」，但 §1.2 给出的精度是
  建筑体块模型平面约 2m、高度约 3m（高层可放宽 5m）——**两个口径互斥**，
  「1:1」不可测量、不可验收，而精度数值可以。
  更麻烦的是「三维实体模型精度分类表」列的档位（体块/基础/标准/体模型/通用符号）
  与正文逐类展开的档位（体块/标准/精细、基础/标准/精细、基础/体模型）
  **四类模型没有一类能对齐**，不锁定就等于把最大的一项成本留成开口条款。
- 代价：需要在需求阶段增加一轮「模型精度确认」，逐类走一遍甲方确认，
  周期上多花时间；且档位一旦锁高（如全部按精细模型），
  外业采集与建模工作量会显著上升，需要同步复核报价与工期。
- 谁拍的：（示例数据，我方主动提出的口径建议，尚未经甲方确认）
